# 🏠 PG Life – Student Accommodation Finder

PG Life is a web application developed using HTML, CSS, Bootstrap, JavaScript, PHP, and MySQL. The application helps users search for Paying Guest (PG) accommodations in different cities, view property details, and manage their accounts through a responsive and user-friendly interface.

---

## 🚀 Features

- User Registration and Login
- Search PG accommodations by city
- View detailed property information
- Interested Property feature
- User Dashboard
- Responsive Design
- PHP & MySQL Database Integration

---

## ⚙️ Installation

1. Clone this repository.
2. Move the project to the XAMPP `htdocs` folder.
3. Create a MySQL database named `pglife`.
4. Import the `pglife.sql` database file.
5. Start Apache and MySQL using XAMPP.
6. Open:

```
http://localhost/PGLife/
```
